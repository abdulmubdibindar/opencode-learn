# Penilaian

Dokumen ini menjelaskan bagaimana penilaian dilakukan dalam suatu mata kuliah di PS PWK ITERA.

## Bentuk Penilaian

^538cc9

Penilaian/asesmen memiliki banyak bentuk:

- Observasi (Praktik)
- Unjuk Kerja (Presentasi)
- Tes Lisan (Tugas Kelompok)
- Tugas Individu
- Tes Tulis (UTS)
- Tes Tulis (UAS)
- Partisipasi (Quiz)
- Laporan Hasil Proyek

## Kolom Penilaian dalam [[Materi Per Pekan]]

^abbce3

Kolom Penilaian dalam Materi Per Pekan terdiri atas 3 anak kolom: **Kriteria dan Bentuk**, **Indikator**, dan **Bobot**

- Kolom **Kriteria dan Bentuk**  berisi bentuk-bentuk penilaian di [[Penilaian#Bentuk Penilaian|Bentuk Penilaian]]. Setiap bentuk penilaian dikaitkan dengan CPMK yang ditetapkan. Satu CPMK dapat dinilai dengan **lebih dari satu bentuk** penilaian. 
- Setiap bentuk dalam suatu CPMK akan memiliki **bobot** penilaian yang jika dijumlahkan semua akan berjumlah **100%**. Kolom **Bobot** berisi bobot bentuk penilaian per CPMK untuk setiap pertemuan yang berusaha memenuhi CPMK di pertemuan tersebut.

| Bentuk Penilaian         | CPMK-a-1 | CPMK-b-1 | CPMK-b-2 |
| ------------------------ | -------- | -------- | -------- |
| Tes Tulis (UTS)          | a        | -        | -        |
| Tes Tulis (UAS)          | -        | b        | -        |
| Unjuk Kerja (Presentasi) | -        | -        | c        |

**a + b + c = 100**

- Kolom **Indikator** berisi keterangan apa yang diujikan untuk setiap bentuk penilaiandi pertemuan tersebut.
