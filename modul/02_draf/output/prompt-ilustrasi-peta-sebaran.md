# Prompt Ilustrasi Peta Sebaran Masalah (untuk subbab 4.2.5)

Gunakan prompt berikut pada alat pembangkit gambar untuk membuat ilustrasi subbab **4.2.5 Menandai Sebaran Masalah pada Peta**. Simpan hasilnya sebagai `images/peta-sebaran-masalah.png`, lalu hapus komentar penanda `<!-- ILUSTRASI PETA SEBARAN ... -->` di `bab.qmd` dan sisipkan `![...](images/peta-sebaran-masalah.png)`.

## Prompt (bahasa Inggris, untuk hasil terbaik)

> Clean, flat vector illustration for an urban-planning textbook, viewed at a slight high angle. A large A0 map of a sub-district (kecamatan) administrative area is pinned to a wall or laid on a work table. The map shows light gray boundaries of several villages/kelurahan. On the map, colorful sticky notes (yellow, blue, pink, green) are placed on different villages, each sticky note handwritten with a short entry code like "FL-01", "SE-01", "IN-01", "KB-01", "SK-01". A few sticky notes cluster densely on one village, visually showing a concentration of problems. Next to the map, a small cluster of extra sticky notes and colored markers sit on the table. The style is clean, educational, minimal, flat design, soft neutral colors with the ITERA navy accent (hex #003b59), no text other than the small codes, no people, no photorealism.

## Keterangan isi (harus tampak)

- Peta administratif kecamatan dengan batas desa/kelurahan (abu-abu).
- Sticky note warna-warni bertuliskan kode entri singkat (`FL-01`, `SE-01`, `IN-01`, `KB-01`, `SK-01`).
- Konsentrasi masalah terlihat: satu desa menerima banyak sticky note, desa lain sedikit.
- Gaya flat/vektor, bersih, edukatif; aksen warna navy `#003b59`; tanpa teks lain selain kode.
